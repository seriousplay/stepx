# Amoo 统一任务界面 · 0.2.20

2026-10-24 用户确认的整合设计覆盖下面旧文档中 Work / Studio 独立页面的规定：主导航只保留 Amoo。一个任务共用输入框、草稿、附件、执行步骤与成果；完整窗口按需打开右侧预览，小窗口在当前窗口查看，不切到完整模式。普通对话直接发送，复杂任务先确认计划；手机发送与 Studio 草稿同步分别确认。手机 Amoo、自有模型 API 和 Studio 官网账号分别标明，不混用额度。

实现与验证见 `../docs/AMOO_WORKSPACE.md`，视觉参照见 `../docs/design/unified-workbench-20261024/review.html`。

# StepX Companion 设计规范

适用于 `desktop/src/ui/`；Android 伴侣沿用颜色、图标与圆角规范，字号和触控尺寸见 [手机端设计](../docs/design/android/README.md)。目标：像系统工具一样安静、可预期，信息密度适中，不做营销式表达。

## 1. 原则

1. **一屏一件事**：每个页面只解决一个任务，主操作只有一个（Primary 按钮每屏最多 1 个）。
2. **先内容，后装饰**：不使用阴影、渐变、装饰符号和 emoji；层级靠留白、字重和分隔线表达。
3. **文案短而准**：按钮用动词（2–4 字），标题用名词；不写功能介绍，不写“智能”“旗舰”“矩阵”等修饰词。
4. **状态可见**：连接状态、进行中的任务、错误始终在固定位置（侧栏顶部、底部状态栏）。
5. **危险操作二次确认**：删除、发短信等不可逆操作使用行内确认条，不弹窗。

## 2. 布局

```
┌──────────┬──────────────────────────────────────────┐
│ 设备块    │ 页面标题                      页面操作      │  56px
│          ├──────────────────────────────────────────┤
│ 导航      │                                          │
│          │ 内容区（左右 24px 内边距）                   │
│          │                                          │
│ 连接设备  │                                          │
│ 外观      ├──────────────────────────────────────────┤
│          │ ● 状态信息                                 │  28px
└──────────┴──────────────────────────────────────────┘
  216px
```

- 侧栏固定 216px；内容区最小宽度 760px。
- 列表/详情（短信）：左栏 296px，右栏自适应，各自滚动。
- 概览、应用、文件、连接为单列内容，最大可读宽度不限，靠面板分组。

## 3. 设计令牌

### 间距（4 的倍数）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `S1` | 4 | 图标与文字、标签内边距 |
| `S2` | 8 | 控件之间 |
| `S3` | 12 | 列表行内边距、面板内元素 |
| `S4` | 16 | 面板内边距 |
| `S5` | 24 | 区块之间、页面边距 |
| `S6` | 32 | 空状态上下留白 |

### 字号

| 令牌 | 字号 / 字重 | 用途 |
| --- | --- | --- |
| `TITLE` | 16 / Semibold | 页面标题 |
| `HEADING` | 13 / Semibold | 区块标题 |
| `BODY` | 12 / Normal | 正文、按钮、输入框 |
| `CAPTION` | 12 / Normal | 次要信息、时间、路径 |
| `MICRO` | 11 / Medium | 标签、表头 |
| `METRIC` | 24 / Semibold | 概览数值 |

不使用 Bold；最多三种字重：Normal、Medium、Semibold。

### 颜色

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `bg` | #FFFFFF | #18181C | 内容区背景 |
| `sidebar` | #F4F4F6 | #141417 | 侧栏、表头、状态栏 |
| `surface` | #F8F8FA | #222227 | 面板内的弱底色 |
| `hover` | #F1F1F4 | #27272D | 悬停 |
| `selected` | #FFFFFF | #27272A | 选中行 |
| `border` | #E5E5EA | #27272A | 分隔线、面板描边 |
| `text` | #18181B | #F4F4F6 | 主文字 |
| `text2` | #71717A | #A1A1AA | 次文字 |
| `text3` | #A1A1AA | #71717A | 占位、说明 |
| `accent` | #18181B | #F4F4F6 | 主按钮、焦点、选中；使用中性色 |
| `success` | #10B981 | #10B981 | 已连接、成功 |
| `warning` | #D97706 | #F59E0B | 待授权、注意 |
| `danger` | #DC2626 | #EF4444 | 错误、删除 |

语义色只用于小面积（状态点、标签文字），不用于大面积底色。

### 圆角

控件 8px；面板 12px；标签 6px；状态点为圆形。具体值以 `ui/theme.rs` 为准。

## 4. 组件

| 组件 | 规格 |
| --- | --- |
| 按钮 | 高 30px，左右 12px。`Primary`（实心 accent）、`Secondary`（描边）、`Ghost`（无底，悬停出底色）、`Danger`（红字描边，确认时实心）。 |
| 输入框 | 高 32px，描边 `border`，聚焦描边 `accent`；占位文字用 `text3`；有内容时右侧出现“清除”。 |
| 分段控件 | 用于 2–4 个互斥选项（筛选、配对方式）。底色 `sidebar`，选中项 `bg` + 描边。 |
| 面板 | `border` 描边、12px 圆角、无阴影；标题在面板外上方（区块标题）。 |
| 列表行 | 高 ≥ 40px，内边距 12px；行之间 1px 分隔线；悬停 `hover`；选中 `selected`。 |
| 标签 | 11px 文字 + 6px 圆角弱底，只用于状态（已连接、USB、待授权）。 |
| 确认条 | 面板内一行：说明文字 + 取消 + 确认，用于删除、发送。 |
| 空状态 | 居中：一句标题（14 Medium）+ 一句说明（12）+ 至多一个按钮。 |

## 5. 页面

对话输入区：文字、待发送附件和操作栏组成一个 16px 圆角容器，文字区域不再套独立边框。图片、文件、手机相册使用同一套 18px 线性图标和 32px 点击区域，悬停显示名称；发送按钮固定在容器右下方。附件在框内展示缩略图、名称、大小和移除入口。内容随实际换行增加高度，达到上限后在框内滚动。空内容、输入法候选未确认和等待回复时禁用发送；简洁、完整模式共享组件及草稿状态。

| 页面 | 结构 | 主操作 |
| --- | --- | --- |
| 概览 | 设备信息 → 指标（电量 / 温度 / 存储）→ 按键 + 截图 | 投屏 |
| Amoo | 对话记录（可滚动）→ 输入区（快捷提示 + 输入框） | 发送 |
| 短信 | 会话列表 ｜ 会话详情 + 输入区 | 发送（需确认） |
| 文件 | 路径 + 工具栏 → 文件表格（名称 / 大小 / 类型）→ 分页 | 上传 |
| 应用 | 搜索 + 范围 → 应用列表 | 安装 APK |
| 小工具 | 分类集合 → 工具详情 → 结果或行内确认 | 由所选工具决定 |
| 连接设备 | 已发现设备 → 无线配对（扫码 / 配对码 / IP）→ 已记住设备 | 连接 |

未连接设备时，依赖设备的页面统一显示空状态“未连接设备 / 连接设备”。

## 6. 文案

- 按钮：刷新、投屏、截图、保存、发送、上传、下载、重命名、删除、连接、配对。
- 状态栏：动作 + 结果，例如“已读取 32 条短信”“截图已保存到 ~/Pictures/a.png”。
- 错误：说明原因 + 下一步，例如“手机未授权调试，请在手机上点击允许”。
- 不在按钮里写快捷键；快捷键见下表。

| 快捷键 | 功能 |
| --- | --- |
| Ctrl/⌘ 1–5 | 切换页面 |
| Ctrl/⌘ 6 | 连接设备 |
| Ctrl/⌘ R、F5 | 刷新当前页 |

## 图标

产品界面统一使用 `assets/icons/` 中 24 × 24 网格、1.75 px 圆角线条的 SVG 图标，由 `ui/icons.rs` 统一着色；导航图标固定为 20 px 容器，绘制尺寸为 16 px。电池、存储、温度、文件类型及操作按钮使用同一套图标。应用列表展示手机 APK 的真实图标；品牌图标和左侧 Amoo 星形标识保留。新增控件优先使用 `ui_icon`，不要添加平台 Emoji。只含图标的操作须提供悬停说明。

默认启动页为首页；读取设备信息前先绘制载入状态，设备发现和数据读取在后台运行。未知、载入中、读取失败和真实的零值应分别表示，不得用演示数据补足未知状态。

## Amoo Work

入口在“智能与开发”，紧接 Amoo；无参数启动仍为首页。工作视图默认只显示宽屏对话，“会话”和“工作文件”按需展开且互斥；“能力中心”集中模型、技能、智能体和 AI 应用目录。模型目录分页并支持搜索，明确区分已配置模型与仅有元数据的目录项，以及云 Amoo 和手机 OpenClaw 的来源。

模型回复、执行日志和实际产物分别展示。内部工具协议折叠为执行记录，不能将模型声称写入的文件当作已存在文件。安装技能展示发布者与安装目标，结果以手机回读为准。未知能力显示原因，不用示例模型、技能或任务填充。

回复使用原生 Markdown 格式，支持标题、粗体、列表、引用、代码、表格与可点击链接，复制保留原文。手机处理、桌面协作与图片创作为同一输入区的三种模式；手机附件不强制选择电脑目录，切到桌面协作时将附件复制到工作目录。图片须等待真实产物，展示缩略图、查看原图和另存为，不将任务下发回执作为生成成功。
