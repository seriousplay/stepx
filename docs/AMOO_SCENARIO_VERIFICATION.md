## 修复的实际问题

- 从确认页返回修改会丢失“处理文件”的选择，导致下一次发送成为普通对话：保留本次选择，按钮改为“返回修改”。
- 回复回执可能清空等待期间输入的新草稿：只清理本次真正提交的内容。
- 生成图片只收到文字或链接就被当成完成：收到实际图片、下载并校验后才登记成果；保存失败明确显示待核对。
- 无自有 API 时应用创作无法开始：接入已连接手机 Amoo 的生成通道，电脑运行检查与修复；已有自有 API 配置继续使用原服务。
- 模型重复请求相同写入可能造成失败：返回已成功操作的回执，不重复写入。无效协议最多纠正两次，格式错误中的操作不执行。
- Word 修改场景出现 done=true 与文件操作同时返回：先要求模型纠正格式，不误判完成，也不执行含糊操作。
- 应用预览混入验收测试数据：完成断言后清理隔离站点数据，再生成首次使用的预览图。
- 折叠执行记录看不到进度：保留一行当前阶段；补充输入框停止按钮和图片下载异常反馈。
