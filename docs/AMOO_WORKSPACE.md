# Amoo 对话与按需工作 · 0.2.24

Amoo 是客户端的 AI 主入口，默认普通对话。文件处理与 Studio 应用创作成为按需使用的能力，不会因为一句话或添加附件就自动切成工作界面。

## 怎么用

1. 直接发送消息，可添加图片、文件或手机相册图片。完整和简洁模式均默认“对话”，看图和文件问答也走对话。
2. 点击输入框内“对话”菜单，选择处理文件、生成图片或制作应用，再点发送。此时展示确认卡：核对使用的资料、模型来源和保存目录，点击“确认开始”。修改要求或附件后应重新核对计划。
3. 完成的文件出现在“生成的文件”。单击预览，按需打开原文件、另存为或发送手机。
4. 应用创作会实际生成、运行检查并保留版本。检查通过后才出现交付按钮；失败会保留已生成文件，核对后重试失败步骤。
5. “资料与能力”打开技能、智能体、模型目录、Studio 官网项目、定时任务及手机 GUI 操作。官网项目的“继续编辑”走已有手机登录交接流程；登录失效时仍需要本人重新登录。

菜单默认向下展开，空间不足时向上展开；选中项有勾选标识。方向键选择，Enter 确认，Esc 或点击菜单外关闭。选择只影响当前请求：确认开始后恢复“对话”；“返回修改”保留本次选择，不会将下一句追问自动变成工作。

欢迎页在可用区域居中，开始对话后输入框固定在底部。标题、正文与输入框保持同一中轴，宽屏限制阅读宽度，窄窗口自然收缩。完整窗口小于 1080 逻辑像素宽时，资料和预览单独展示；关闭后回到原会话，不强制切换窗口模式。

## 保存与交付

- 任务记录保存到本机状态目录 `amoo-workspace/tasks.json`；后台合并保存，退出前刷新草稿。异常退出的执行不会自动重发。
- 每个任务分别保存草稿、附件、实际成果路径与交付回执。任务目录默认位于设置的工作目录下，也可以在计划中另选。
- 本地应用只接收当前任务确认的文字成果，限制类型、大小与目录边界；不会任意扫描其他文件夹。
- 普通文件通过伴侣接收协议发送，核对大小和 SHA-256，手机入口为“StepX伴侣 → 文件 → 接收文件”。
- 应用保存到手机作品库；“发送后在手机打开”单独勾选。
- 同步 Studio 创建官网草稿，使用官网账号及其模型。保存回执后，再次同步同一作品会打开已有草稿，避免重复创建。
- 简洁模式与完整模式共用任务状态，预览不强制退出简洁模式。

## 模型与边界

手机 Amoo 的对话、识图、图片生成和桌面文件执行使用手机模型与手机账号。制作应用未配置自有 API 时，也可以使用已连接手机的 Amoo 账号生成源码，电脑独立运行检查并按反馈修复。已配置自有 API 时使用所选服务，额度与手机分开；确认页显示实际来源。官网项目同步另外使用 Studio 登录状态。

模型能力以手机真实目录和验证结果为准。手机接口不支持手动切换时显示自动路由。断线、错误、停止等待与实际完成分别处理；手机请求尚未确认完成时，不会因队列清空就显示完成。
