## 交互调整

简洁通知默认展示收件箱。选择会话后再显示消息记录与回复框，返回列表保留草稿。系统及常驻通知默认折叠，普通通知与可回复的会话分开展示。回复状态区分发送中、已提交手机应用、手机会话已显示、发送失败和结果未核实。

短信应用没有通知快捷回复接口时，使用手机界面发送：先定位并核对目标号码，再输入和发送，随后核对新增消息和输入框清空。结果未核实不会自动重发，此方式需要手机解锁且允许界面操作。通知快捷回复只表示手机应用已接受请求，不能据此声称对方已收到。

## 验证方法与范围

验收驱动调用客户端正常的 UI action 和后台工作线程；附件选择由测试文件路径替代系统文件选择器，上传、识图、消息与发送结果均来自真实手机。测试入口仅在 `ui-capture` 构建并显式指定验收参数时启用，发布构建不包含它。

页面布局评审使用演示数据，功能验收使用真实连接。此次未在 Windows、macOS 或其他聊天应用上重跑手机界面发送测试，不将短信结果泛化为所有应用均已通过。

详细诊断保留在本机 `diagnostics/compact-live-20261024/`，包含私人会话信息，不随公开文档发布。
