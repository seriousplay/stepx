# Google 服务通用适配与验收

版本：StepX Companion 0.2.28，2026-10-25。

本轮修复公共依赖，使新安装的应用能够使用系统 Google 登录与应用链接验证入口，并在 Google 组件被替换后恢复权限。适配范围为已安装正版 Google 服务的 StepX PZ261A / pandora、Android 16、172 固件；其他固件需重新校验，不能直接套用。

## 问题与处理

| 层级 | 发现的问题 | 已实现的处理 |
| --- | --- | --- |
| 基础服务 | 组件存在，但更新后权限可能重新计算；旧回执会误报正常 | 校验三件套当前启用状态，逐项回读当前权限；回执绑定启动 ID、系统进程和组件版本 |
| 通用 Google 登录 | OEM 系统未发现官方 Google 凭据提供者 | 校验 Google 签名、服务声明及权限后登记提供者，保留其他密码管理器 |
| 登录回跳与应用链接 | 系统缺少域名验证代理，GMS 调用会被拒绝 | 接入官方 Google 的验证接收器，仍由 Android 正常进行 HTTPS 网站归属验证，不强行批准域名 |
| 更新恢复 | GMS 或商店替换后需要电脑重新适配 | 手机后台监听这两个包的更新，延迟合并后串行恢复；不轮询，不重复进行原生注入 |
| 开机恢复 | 进程变化、旧回执以及延迟故障未被完整识别 | 使用现有开机组件恢复，操作互斥；成功前增加 20 秒系统进程稳定性检查；原生故障后不自动循环重试 |
| 使用反馈 | 商店可用被误当成所有应用都可用 | 桌面 Google 工具分项显示基础组件、登录、更新恢复、链接验证和账号存在状态，提供修复入口 |

公共修复不读取账号令牌，不清除应用数据，不写入持久 SYSTEM/PRIVILEGED 包标记，不修改用户的默认链接打开偏好。安装升级前保存旧开机组件与配置；失败记录保留供回退核对。

## 真机验收

设备版本：GMS 26.41.31（264131035）、Play 53.6.15（85361540）、GSF 36。

| 场景 | 实际结果 |
| --- | --- |
| Google 权限 | 153 项当前授权检查通过 |
| GMS 包替换 | 备份完整 13 个 APK 后，以 `install-multiple -r` 覆盖安装同版本；包更新监听实际触发，自动恢复 153 项权限、凭据提供者和链接验证服务。未清数据、未执行 USB 修复 |
| 手机完整重启 | 首次手动解锁后，开机回执、延迟稳定性检查、Google 通用健康检查通过；未手动开启伴侣或执行 USB 修复 |
| 账号保留 | 覆盖安装和重启后 Google 账号数量保持 1；测试仅记录数量 |
| Gemini | 重启前后能进入对话并进行真实问答；具体界面证据保存在本机私有诊断目录 |
| Gmail | 进入已登录的邮件主界面，没有读取或打开邮件内容 |
| Google Play | 进入商店主界面并浏览应用；本轮没有新增购买行为 |
| App Links | 通过系统重新验证后，X 的主要 `x.com`、`twitter.com` 域名获得 `verified`；`call.x.com` 未通过，保持原结果 |
| X 原生 Google 登录 | 已能选择 Google 账号并交接凭据，但 X 服务端的 Integrity 校验返回 214，硬件证明校验也失败。尚未修好，详见 [原生登录失败定位](X_NATIVE_LOGIN_DIAGNOSIS.md) |
| X 官方网页 | 已登录的官方网页入口仍可使用，作为单独的替代入口；不冒充原生登录修复 |
| 健康状态下重复修复 | 返回 `already_ready`，不重复安装、修改权限或重启服务 |

覆盖安装验证了真实的包替换恢复路径，不等于对尚未发布的 GMS 新版本完成兼容验证。若 Google 改变签名、组件或系统 API，检查将显示未就绪，需要重新适配。

## 稳定性与边界

本轮最初两个新增的直接原生探针触发了系统服务重启，已停止使用并恢复既有基线；账号保留。最终实现把新增登记放在正常 Android 后台线程，增加互斥与延迟检测。后续组件覆盖安装、应用使用和完整重启验收未出现同类故障。

Google 设备认证、Play Integrity、应用服务器风控、地区及账号资格是独立条件。当前没有获得或宣称获得官方设备认证；公共依赖就绪不能保证全部第三方应用接受登录。未来新应用应先使用公共健康检测，再单独验证真实登录、通知或地图等业务，不给每个应用盲目追加高权限。

Gemini 此前在本机应用的版本限定配置与 OEM 精确跳转规则仍保留；它们不属于本轮通用恢复机制，也不据此承诺其他固件上的 Gemini 必然可用。
