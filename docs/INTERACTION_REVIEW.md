# 操作确认与反馈审查

Desktop 0.2.13 / Android StepX伴侣 0.1.25，2026-10-24。

## 用户看到的规则

- **选择不等于执行**：类型、目录、设置开关先形成草稿；底部固定显示未保存状态和确认入口。
- **确认单说明目标与后果**：电脑、指定手机、Studio 账号分别写明。涉及迁移时列出类型、保留时间、原件保存目录、何时清理与离线限制。
- **取消保留编辑；放弃才恢复原值**。切换模块、简洁模式或退出前提醒未保存。错误不清空草稿。
- **提交与完成分开**：操作提醒先记录确认提交；手机回读、传输回执或执行结果到达后再显示反馈。记录保留本次运行的最近 30 条，不记录密钥。
- **浏览操作即时响应**：筛选、排序、翻页和本地预览仅改变显示，不增加执行确认。扩容页明确标注筛选不改变迁移规则。
- **停止保持直接可用**：停止任务、停止播放仍立即响应，不用确认阻碍停止操作。

## 各模块审查

| 模块 | 审查与处理 |
| --- | --- |
| 首页 / 账号用量 | 读取、刷新为只读；功能入口进入对应模块，不在首页隐式开启迁移或同步。 |
| 设置 | 通用、文件位置、Work 成果回传与通知改为统一草稿；固定保存/放弃；按实际变更列出摘要。关于和更新日志在设置内。 |
| 存储扩容 | 已生效规则与编辑规则分开；选择文件夹不再立即写入。确认开启后，串行保存并回读手机；失败阻止本机自动迁移，保留编辑。暂停、取回原件也有影响说明。 |
| 背屏 / 游戏 | 保持选择与应用分离；应用前展示名称、亮度、帧率及临时播放时长，说明会替换手机效果；应用回执和错误进入提醒。停止无需二次确认。 |
| Amoo | 输入和附件为待发送内容；输入框标明发送到手机 Amoo。发送按钮是明确提交动作，不在每次发消息时额外打断。原有安全授权继续保留。 |
| Amoo Work | 工作目录、自动发送交付成果通过设置统一确认；自动回传默认关闭，提示会发送至任务所连接的手机。技能安装保留原有安装确认；任务的启动/停止及附件仍使用原有流程。 |
| Studio | 推送到手机、同步到官网、保存模型服务增加统一确认；“测试/获取模型”明确告知会保存当前配置并连接服务。保存失败保留密钥草稿，成功后清空输入框。离开模型设置会提示未保存。 |
| 消息与短信 | 直接短信预检完成后，以统一确认单显示收件人、SIM、正文和段数；取消保留草稿。IM 明确发送按钮与原有发送回执继续保留。 |
| 手机推送 | 清除通知说明会同步清除手机通知栏；在手机打开说明会切换手机界面。通知偏好统一进入设置编辑，不再静默保存。 |
| 电话 | 号码与 SIM 预检后显示统一确认，点击后才拨打。挂断保持直接执行。 |
| 文件 | 上传先选择文件，再确认手机位置、文件清单及同名覆盖提示；回收站与永久删除分别说明后果。新建/重命名保留表单提交，下载保留系统保存对话框。 |
| 应用 | 卸载显示包名、目标手机和应用数据影响；强行停止有影响说明。导出保持系统目录选择，系统应用不可卸载的限制保留。 |
| 小工具 | 安装组件、系统服务修改增加统一确认；已有 Google 维护、OTA 安装/清理等专用确认保留详细风险和回滚信息。连接前仍不能执行设备操作。 |
| 连接设备 | 扫描、状态读取和配对结果继续即时反馈；配对中的系统授权仍由手机确认。扩容配置正在提交时禁止切换设备或退出；确认期间目标变化会拒绝执行。 |
| Android 伴侣 | 扩容增加固定确认入口、保存内容摘要、取消/放弃区别和返回提醒；显示与后台连接开关先确认。文件恢复与缓存清理说明占用空间和离线影响。 |

## 回归边界

- Linux 原生界面测试使用隔离配置，不写用户设置：保存前不落盘、取消保留、跨页提醒、保存失败保留、通知草稿、迁移确认、操作记录、托盘收起/恢复、目标变化拒绝、短信及文件传输取消。
- 授权 PZ261A 真机测试 Android 页面：勾选视频、返回提醒、取消继续编辑、放弃返回、再次进入恢复原选项；手机迁移策略、迁移数量及释放空间前后不变；Android 显示开关弹出确认，取消后原偏好保持不变。
- 未为验证界面而开启用户真实文件的迁移，也未执行卸载、拨号、发短信、删除或云端同步。
- 本轮没有 Windows/macOS 实机。已有设备操作实现继续使用原验证路径；代码审查和确认流程通过不等于本轮重新执行了全部有副作用的操作。
