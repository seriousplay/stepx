# 投屏控制验收 · 2026-10-23

测试设备：STEPX Neo / PZ261A；系统：Linux（XWayland）。未包含设备序列号、IP 或手机截图。

## 窗口交互

- 工具页保留开启 / 结束投屏入口，不嵌入控制侧栏预览。
- 侧栏定位到本次 scrcpy 进程的窗口，移动和缩放后核对几何位置。
- 最小化后侧栏隐藏，恢复窗口后侧栏重新显示。
- 点击结束投屏后，画面与侧栏均关闭；关闭侧栏窗口同样结束投屏。

## 按钮与手机状态

通过侧栏窗口的鼠标按下 / 松开事件和真实 UI 命中测试触发按钮，使用 ADB **只读回查**验证结果。

- 主页：从系统设置返回手机桌面。
- 返回：从设置返回桌面。
- 多任务：Launcher 的 `inOverviewState` 变为 `true`。
- 音量：减小后读数变化，再增加恢复原读数。
- 截图：生成有效 PNG，客户端进入可保存截图状态。
- 结束投屏：两个窗口均消失。

连续三轮开始、按键、截图、结束和再次打开后关闭侧栏均完成；界面心跳最大间隔 1302 ms，未出现长时间停顿。另有慢进程退出回归测试，保证结束操作不等待进程退出。

这些是 Linux 真机结果；macOS / Windows 的原生构建和功能实测分别记录，不将构建成功等同于交互验收。
