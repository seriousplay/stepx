StepX 首个公开预览版：将手机 Amoo、Work 文件协作、背屏创作和常用设备工具带到电脑。

### 重点功能

- **Amoo**：手机会话同步、格式化消息、附件与图片、定时任务和接口可用的 token 信息。
- **Amoo Work**：围绕文件的工作区、文档/表格/PPT 输出、图片缓存和成果预览。
- **背屏**：像素图案、动画、太空人、亮度时间控制和 StepX伴侣小游戏。
- **小工具**：空间释放、手机 OTA 检查、投屏、APK 管理、Google 服务诊断与伴侣安装引导。
- **新手引导**：首次启动弹窗说明开启开发者选项、USB 调试和电脑授权，支持跳过、重新查看及真实状态检测。
- **连接与管理**：USB / 无线配对、文件互传、短信、电话、应用与真实设备状态。

- **界面整理**：账号与用量入口移至首页，连接状态统一到底部，精简关于页；版本升级为 0.2.0，构建时间以 12 位数字显示。

### 下载与运行

按系统和芯片选择 `linux-x86_64`、`macos-arm64`、`macos-x86_64` 或 `windows-x86_64`。解压整个目录后运行；不要只移动可执行文件。macOS 使用包内 StepX.app。ADB / scrcpy 已随包提供；高级脚本需要 Python 3.10+。每个下载文件都有 SHA256 校验文件。

### 验证范围与限制

四个平台通过原生构建、核心自动化测试和包内程序版本启动检查。Linux 是当前开发与设备联调平台；macOS / Windows 尚未声明完整的实体手机、图形界面和驱动兼容性验收。当前包没有 Apple 公证或 Windows 商业代码签名。

Amoo 和背屏依赖手机固件、账号权限与服务接口。Google 相关入口不代表设备已经通过认证。此发行版为社区预览，系统修改与删除操作前请备份。界面文档中的演示截图使用虚构数据，功能验收以实际设备结果为准。
