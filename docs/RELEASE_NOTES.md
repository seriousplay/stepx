## 0.2.0

StepX Companion 首个公开预览版：为 STEPX Neo 手机（当前适配 PZ261A）打造的桌面伴侣。电脑直接与 Amoo 对话，复用手机模型与账号 Token 权益完成 Work 任务，压缩与释放手机空间，并提供 Google Play 安装和背屏创作。

### 重点功能

- **压缩手机空间**：在手机本地压缩适合的文档，校验收益后替换原文件，支持还原，并集中处理重复文件与可清理项目。
- **Amoo**：手机会话同步、格式化消息、附件与图片、定时任务和接口可用的 token 信息。
- **Amoo Work**：围绕文件的工作区、文档/表格/PPT 输出、图片缓存和成果预览。
- **投屏响应**：窗口位置查询与退出等待移到后台，关闭侧栏不再重建全局图形实例；修复按钮事件和窗口关闭清理。
- **投屏控制**：跟随投屏窗口的竖排侧栏提供主页、返回、多任务、音量、截图和结束投屏；关闭任一投屏窗口结束本次会话。
- **性能与稳定性**：修复背屏无限布局导致的无响应，点阵统一绘制；未打开模块按需加载，离开页面暂停预览，减少空闲刷新和重复解析。
- **单实例启动**：重复打开唤起现有窗口，不重复占用设备和后台任务；最小化后恢复，异常退出后锁自动释放。
- **界面与品牌**：统一 StepX Companion 名称和独立图标，按实拍修正手机外框，首页显示可读取的 Token 用量。
- **背屏设置**：17 × 23 点阵与 379 颗灯珠，图案、太空人动画、图片转像素、亮度、播放速度和时长，先预览再应用到手机。
- **背屏游戏**：StepX伴侣提供「重力对齐」，三敲开局、左右倾斜控制，长条与槽位从 5 格到 1 格循环挑战、累计积分，翻面退出；安装并启用后可脱离电脑游玩。
- **小工具**：空间释放、手机 OTA 检查、投屏、APK 管理、Google 服务诊断与伴侣安装引导。
- **新手引导**：首次启动弹窗说明开启开发者选项、USB 调试和电脑授权，支持跳过、重新查看及真实状态检测。
- **连接与管理**：USB / 无线配对、文件互传、短信、电话、应用与真实设备状态。
- **界面整理**：首页直接展示已同步的 Token 用量，支持后台刷新与详情，连接状态统一到底部，精简关于页；版本升级为 0.2.0，构建时间以 12 位数字显示。

### 下载与运行

按系统和芯片选择 `linux-x86_64`、`macos-arm64`、`macos-x86_64` 或 `windows-x86_64`。解压整个目录后运行；不要只移动可执行文件。macOS 使用包内 StepX Companion.app。ADB / scrcpy 已随包提供；高级脚本需要 Python 3.10+。每个下载文件都有 SHA256 校验文件。

### 验证范围与限制

发布流程对四个平台执行原生构建、核心自动化测试和包内程序版本启动检查，全部成功后才生成完整发行草稿。Linux 是当前开发与设备联调平台；macOS / Windows 尚未声明完整的实体手机、图形界面和驱动兼容性验收。当前包没有 Apple 公证或 Windows 商业代码签名。

Amoo 和背屏依赖手机固件、账号权限与服务接口。Google 相关入口不代表设备已经通过认证。此发行版为社区预览，系统修改与删除操作前请备份。界面文档中的演示截图使用虚构数据，功能验收以实际设备结果为准。
