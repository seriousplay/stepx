## 结构

设置在主导航底部，关于不再单独占用导航。分为通用、文件与存储、Amoo Work、通知和关于。目录使用更改按钮，布尔偏好使用开关；操作后自动保存。Studio 模型配置有明确入口，Amoo Work 继续使用手机模型。

图稿通过 Codex 内置 imagegen 生成，参考现有客户端。第二版按用户反馈简化结构，文件为 `docs/design/settings-motion/settings-v2.png`，提示词为 `prompt-v2.txt`。真实原生窗口截图在 `diagnostics/settings-motion-20261024/`，不是用图稿代替界面。

## 验证

- 原生 Linux 窗口验证：分类切换、设置落盘、主题、减少动态效果、实际隐藏和恢复窗口；关闭托盘后取消后台隐藏。
- 49 项 UI 回归通过。设置持久化 3 项、Work 交付队列 2 项、文件传输校验 2 项通过。
- 授权的 PZ261A 真机：新目录接收合成文件；关闭自动发送时不传输；离线保留原件，重连送达；重复回执不生成第二份；测试文件已清理。
- Android 真机：开关减少动态效果、切页保持偏好、文件页读取及连续快速切换；测试后还原原有动画偏好。保留嵌入式 Neo 引擎的私有构建安装成功。
- 视觉检查：常规、文件、Work、关于与手机设置；窄窗口可滚动，正常窗口留白清晰。

## 范围与边界

自动回传默认关闭，只发送桌面协作生成在 `Amoo Work Outputs` 内的交付文件。不会扫描、搬走或同步整个项目，原文件留在电脑。使用现有 USB 或无线 ADB 文件通道，按手机序列号绑定接收方；断线后重试，不会改发另一台手机。单文件最大 256 MB。

Linux 实机与 Android 实机已验证；Windows、macOS 的托盘表现未在本轮真机验证。后台隐藏使用客户端的关闭按钮；系统强制结束进程仍会退出。当前测试未开启用户真实文件的自动迁移。
