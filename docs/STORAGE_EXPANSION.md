# 存储扩容

这项能力在现有 StepX Companion 内运行。desktop 左侧「文件」下面的「存储扩容」显示迁移状态与文件库；手机伴侣的首页、文件页提供同一文件库。

## 使用

1. 通过已授权的 USB ADB 或现有无线 ADB 配对连接手机。电脑客户端需要运行。
2. desktop 左侧导航 → **存储扩容 → 设置自动迁移**。第一步选择文件类型和迁移时间；黑色“✓ 已选择”表示已选中。保留最近 7 天 / 30 天，只会迁移比这些天数更早的文件。希望迁移近期文件可选择“写入完成后迁移”，文件仍需停止写入至少两分钟。
3. 第二步选择电脑保存文件夹，页面显示最终的 `StepX Storage` 路径。若缺少权限，在手机 StepX伴侣 → 文件 → 存储扩容中允许文件管理；无需 Root。
4. 第三步先检查文件清单，显示可迁移数量、大小、保留期内数量和最早迁移时间。点击“确认并开启自动迁移”，在确认框核对影响后保存到手机；取消或返回不会应用草稿。保存成功回到状态与文件库。修改期间已有规则仍继续有效。
5. 在两端按分类、日期、名称、大小查找文件。手机可打开原件或恢复到原目录；恢复时遇到同名文件会另存，电脑副本保留。

拍摄内容指 `DCIM` 根目录和 `DCIM/Camera` 内支持的媒体；文档指 `Documents` 和 `Download` 中的常用文档格式。隐藏文件、应用私有目录、符号链接、空文件和超过 32 GiB 的单文件不参与自动迁移；刚写入的文件至少等待两分钟。

## 为什么还没有自动迁移？

状态页会显示当前规则及等待原因：未连接、未授予文件权限、未选电脑目录、目录离线、绑定了另一台电脑、已暂停或文件仍在保留期内。“文件检查”展示当前条件下的数量和最早迁移时间，点击“检查迁移”可主动刷新并重试失败文件。识别到文件不等于已满足迁移时间；例如刚拍摄的照片在“保留最近 7 天”规则下会继续留在手机。

自动任务沿用当前已确认规则；查看草稿的检查结果不会改动规则或清理文件。检查统计最多每 30 秒刷新一次，主动刷新和规则变更会重新检查；实际迁移前逐个复核文件状态。

## 文件入口与离线状态

- 原位置保留 `.stepxlink`；支持文件类型关联的文件管理器可用 StepX伴侣打开。
- 伴侣文件库及 Android 系统文件选择器的「StepX · 电脑扩容文件」入口可访问归档文件。系统相册的「StepX Companion」相册保留带标记的小尺寸预览图（照片或视频封面）；原件仍在电脑。
- 从系统相册选择预览图 → 分享 →「取回电脑原图」，在线时自动取回、校验并在相册打开原件；无需进入伴侣文件库查找。单击照片自动取回依赖原厂相册私有云接口，目前未接入；不把缩略图当作原图。
- 电脑离线时保留媒体缩略图；已取回且缓存未清理的原件可离线查看，其余需要重新连接保存原件的电脑。
- 查看缓存按 512 MiB / 24 小时策略清理旧文件，当前打开的文件保留。也可手动清理，不删除电脑原件。
- 恢复到手机的文件不自动再次迁移。恢复后移除文件库记录也保留此排除标记。

## 完整性与空间

依次执行手机原件校验 → 传输到电脑临时文件 → 电脑校验 → 文件与回执落盘 → 手机再次校验 → 生成相册预览（媒体预览失败则保留原件）→ 保留入口 → 经已授权 ADB 通道删除暂存原件 → 手机确认完成。任何校验失败均不清理原件。设置修改、设备变化、进程中断可通过日志恢复或重新校验；失败文件退避五分钟，不阻塞其他文件。

部分 StepX 固件会把普通应用删除的文件移动到系统回收站。扩容使用已有授权的 ADB 文件通道执行最终清理，并验证文件已不存在；不会清空其他应用或用户的回收站。显示的释放量按已确认清理的原件大小扣除查看缓存、文件库缩略图和相册预览图计算，不是整个磁盘的实时可用空间增量。

电脑保存目录是原件所在位置，需要用户自行妥善保管或备份。有迁移记录时不支持直接换目录，避免手机入口指向失效位置。默认关闭自动迁移。

验证入口：`desktop/examples/verify_expansion.rs`、`verify_expansion_auto.rs`、`verify_expansion_space.rs`、`verify_expansion_gallery.rs`。真机测试仅处理专门生成的文件，不自动迁移用户照片、视频或文档。详细日志保存在本机忽略目录 `diagnostics/storage-expansion-20261024`，不公开设备数据。

运行验证程序时，必须通过 `STEPX_AUTHORIZED_SERIAL` 明确指定允许测试的物理设备序列号，并提供传输地址和私有输出目录。自动视频验证需要该目录中的 `test-video.mp4` 测试素材；如果扫描到其他符合条件的文件，程序拒绝启动自动迁移测试。

相册集成真机验收：原生相册展示预览、从原生分享菜单取回、原件 SHA-256 一致、离线未缓存提示、离线已缓存打开、恢复时清理自有预览，以及无效媒体预览失败保留原件。测试素材均为生成图片，未迁移用户照片。
